# Simple Interest Calculator

## Project Description

This project contains a simple interest calculator written as a Bash script. It computes the simple interest based on user-provided input values.

## Simple Interest Formula

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Input Fields

- **Principal** – The initial amount of money
- **Rate of Interest** – The annual interest rate (in percentage)
- **Time Period** – The duration in years

## Usage

```bash
bash simple-interest.sh
```

You will be prompted to enter:
1. Principal amount
2. Rate of interest (%)
3. Time period (years)

The script will then calculate and display the simple interest.

## Example

```
Enter the principal: 1000
Enter the rate of interest: 5
Enter the time period (in years): 3
Simple Interest = 150
```
